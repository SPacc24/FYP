Main commands
-------------

Adaptive scan setup
-------------------

The landing page now runs one adaptive vulnerability scan. Enter authorised IP
addresses or CIDRs, choose numerical TCP coverage, configure UDP separately,
and optionally open Advanced settings. Complete TCP coverage tests 1-65535.
Common and custom coverage are faster but the report will disclose untested
ports. Every open port is fingerprinted before a protocol module is selected.

Only one microbatch runs at a time for each target. The Concurrent targets
setting controls how many different targets can perform port discovery at once.

Install once from the repository root:

   chmod +x install.sh
   ./install.sh

Start the dashboard:

   bash start.sh

Open locally:

   http://127.0.0.1:5000

For access from the Windows host browser:

   APP_HOST=0.0.0.0 bash start.sh

Then unlock the browser session with the generated OPERATOR_TOKEN.

Show generated local secrets:

   python project/scripts/bootstrap_env.py --show-secrets

Start Metasploit RPC with the generated METASPLOIT_RPC_PASS:

   msfrpcd -U msf -P <METASPLOIT_RPC_PASS> -a 127.0.0.1 -p 55552

See README.md for the full runbook.
